# Security

This is a reference implementation using synthetic data. Do not expose the demo
configuration to the internet or connect it to customer systems.

Report vulnerabilities through this repository's **Security → Report a vulnerability**
button. Do not post credentials, personal data or an exploit against a real
deployment in a public issue. There is no support SLA for this example.

The README and design notes describe the implemented guarantees and the work
still needed before production use.
